astab Privacy Policy

Effective November 6, 2026 · Maintained by aste2d

astab is a new-tab extension for open tabs, bookmarks, saved pages, notes and focused time. It has no account system, advertising, analytics, telemetry or developer-operated data server. The developer does not receive your tabs, bookmarks, notes or timer activity.

Information used on your device

  • Open tabs: titles, URLs, identifiers, window membership, pinned status and icons are used to display, group, focus, reorder, save and close tabs. astab does not request Chrome’s browsing-history permission and does not read webpage bodies.
  • Bookmarks: titles, URLs, folders and their order are read to display and search your bookmarks. astab does not create, edit or delete Chrome bookmarks. Chrome’s own sync settings continue to control your bookmarks.
  • Saved pages and notes: saved titles and URLs, todo titles, note text, timestamps and completion states are stored locally so you can return to them.
  • Preferences and timers: layout order, colors, settings, timer state, custom icons, uploaded backgrounds and the latest downloaded wallpaper are stored in Chrome’s local extension storage. astab does not sync these records to a developer service.
  • Clipboard actions: Copy title writes the selected title when you click it. The custom-icon editor can read an image when you explicitly choose Paste or paste an image into the editor. astab does not monitor your clipboard.

Network connections

  • Wallpapers: Forest collection is enabled by default. It downloads images from images.unsplash.com, using a curated eight-photo collection that rotates daily. Optional Daily discovery requests public photo metadata and images from picsum.photos and its image CDN, including fastly.picsum.photos. These providers receive connection information such as your IP address and the requested photo identifier. Wallpaper requests omit credentials and referrers and do not contain tab URLs, bookmarks, notes or saved pages.
  • Offline behavior: the latest downloaded image is cached locally. Failed downloads keep the existing background or use the solid theme when no image is available. Choose My background / Solid color in settings to stop online wallpaper requests.
  • Search: a query you submit is passed to Chrome’s configured search provider. If Chrome’s search API is unavailable, the extension opens a Google search instead. astab does not retain the query or send it to the developer.
  • Icons and links: site icons use Chrome’s favicon service. Clicking a website, photo credit or author link opens that destination normally. Those services operate under their own privacy policies.

Third-party policies: Unsplash · Lorem Picsum · Fastly. These services do not sponsor astab.

Retention and your choices

Extension records remain on your device until you change or remove them using the interface, clear the extension’s local data, or uninstall astab. Some dismissed todos and saved items can remain in local storage; uninstalling removes the extension’s local storage. Uninstalling does not delete your Chrome bookmarks or ordinary browsing history. If you contact the author yourself, information you include in that message is handled by the service you choose to use.

Limited use and sharing

astab complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only for the user-facing features described here. User data is not sold, used for advertising or credit decisions, transferred to data brokers, or used to train machine-learning models. The developer has no remote access to extension records. The ordinary network requests described above are the only external connections made by these features.

Permissions

tabs displays and manages open tabs; bookmarks displays folders and links; storage saves local preferences and content; search uses the current search engine; favicon displays site icons; alarms finishes timers after a new-tab page closes. astab requests no website host permissions. It executes no remotely hosted code.

Changes and contact

This policy will be updated when the extension’s data practices change. The effective date appears above. Questions and privacy requests can be directed to the maintainer through github.com/aste2d.
