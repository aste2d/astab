# Changelog

## 2.1.2 — 2026-11-06

First public astab release on GitHub.

- Preserve the two-column new-tab layout, with draggable tab-group cards.
- Add independent bookmark-folder navigation, global search and optional All Bookmarks expansion.
- Keep saved pages, todos and notes; add a compact Pomodoro timer.
- Rotate a curated forest wallpaper collection daily, with cached/custom/solid offline fallback.
- Make automatic cleanup of other new-tab pages configurable and enabled by default.
- Add custom palettes, copy-title buttons and two-click tab cleanup controls.
- Include installation, manual update and privacy documentation.
